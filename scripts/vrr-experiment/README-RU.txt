Проверка VRR — одна сборка, несколько готовых режимов.

1. Полностью закрой все запущенные Magpie.
2. Распакуй архив в отдельную папку.
3. Если FG требует твоих совместимых DLL для RTX 3080, используй их из
   рабочей версии. Не заменяй новый Magpie.exe старым.
4. Для нового варианта управления запусти 6-Opaque-native-input.cmd.
5. Включи обычный FG-профиль в игре. Нажми обычную горячую клавишу Scale.
6. Проверь частоту в меню монитора. Для остановки — та же горячая клавиша.

Режим 3: непрозрачное полноэкранное окно, фокус у Magpie.
Режим 2: непрозрачное окно, фокус у исходного приложения.
Режим 4: layered-окно, фокус у Magpie.
Режим 1: VRR с обычным управлением.
Режим 5: отдельная проверка вывода с VSync.
Режим 0: возврат к обычным настройкам.

Режимы 2/3/4 предназначены для проверки изображения: управление игрой
может не работать. Перед сменой режима полностью закрой Magpie.
Выбранный режим хранится в vrr-experiment-mode.txt рядом с программой.
Запуск режима 0 или удаление этого файла сбрасывает выбор.
После проверки пришли logs/magpie.log и logs/magpie.1.log.

Сборка проверена компиляцией Windows MSVC x64. Работу VRR подтверждают
проверка драйвера и показания твоего монитора, а не факт успешной сборки.

Режим 6: непрозрачное окно без захвата фокуса, обычная логика координат
и ограничения мыши. Под физическим курсором вырезается квадрат 65x65
пикселей: Windows доставляет щелчки исходной игре напрямую. Этот вырез
может быть виден как небольшой участок исходного изображения и может
отключить DirectFlip/G-SYNC. Это эксперимент, а не подтверждённое решение.
При быстром перемещении мыши щелчок может опередить обновление выреза.
Горячая клавиша остановки остаётся доступной. Режим 1 — возврат к обычному
управлению. Режимы 2/3/4 по-прежнему только для проверки изображения.

Режим 7: запуск 7-Opaque-136FPS.cmd. Основан на режиме 6, но DLSSFG
выводит кадры с постоянным целевым интервалом 7,353 мс (136 FPS).
При FG x2 поставь лимит игры 68 FPS. Если игра не держит 68 FPS,
ровные 136 невозможны. Кадры готовятся до срока вывода; после задержек
нет быстрого потока догоняющих кадров. Последние 200 мкс ожидания
уточняются с обработкой входящих сообщений. Вырез и дефект курсора
режима 6 пока сохранены: эта сборка проверяет только ритм вывода.
Режим 6 оставлен для сравнения. Идеально ровный график не гарантируется.
