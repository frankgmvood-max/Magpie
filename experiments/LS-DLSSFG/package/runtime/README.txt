Place the compatible nvngx_dlssg.dll and companion runtime DLLs from your
working FG setup here. No NVIDIA runtime or RTX 3080 compatibility mod is
bundled. Stock DLSS FG is not sufficient for RTX 3080.
Process-level proxy loaders (dxgi.dll, version.dll, d3d11.dll) are NOT loaded
from this folder. Do not replace the LS addon manager's proxy with one.
