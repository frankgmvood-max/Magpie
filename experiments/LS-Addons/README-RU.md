# Экспериментальные аддоны LS 0.3.0

В комплекте DLSS FG 0.3.0 с исправлениями восстановления, отдельные Smooth Motion 0.1.0 и RTX Video HDR 0.1.0.
Требуется установленный Echo-Storm LS addon manager 0.9.38 / API >= 1.1.

Закройте LS. Передайте путь к каталогу с LosslessScaling.exe скрипту Install-Addons.ps1 либо перенесите LS_OutputBridge.dll в этот каталог,
а каталоги внутри addons — в его addons. Менеджер и его proxy DLL не заменяются.
Существующие LS_DLSSFG.ini и runtime для RTX 3080 сохраните. Скрипт сохраняет все существующие INI и делает резервные копии заменяемых файлов.
Установка не включает автоматическую смену настроек LS или системы.

Для установки скриптом откройте PowerShell в распакованном каталоге и выполните, заменив путь на свой:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Addons.ps1 -LSDirectory "C:\Program Files (x86)\Steam\steamapps\common\Lossless Scaling"
```

После запуска LS включите нужный аддон в менеджере, откройте его Settings, отметьте Enable и подтверждение отключения штатной функции LS,
затем Save and apply. Smooth Motion и DLSS FG используются по отдельности. RTX HDR можно сочетать с одним генератором.
Если в INI существующих аддонов функция уже была включена, установщик сохраняет этот выбор.

DLSS FG: используются ваши совместимые runtime/mod DLL для RTX 30. Исправлены новые таблицы Present, повторное использование адреса устройства,
история после сворачивания/паузы и ситуация, когда дубликат мешал передать reset в NGX. В меню есть автоматическое восстановление и кнопка пересоздания.
Непрерывный отказ runtime от интерполяции приводит к ограниченным попыткам восстановления, а не бесконечным пересозданиям.

Smooth Motion: отдельная альтернатива x2. Отключите DLSS FG и native LSFG, затем включите Smooth Motion в его меню.
Разрешён только проверенный профиль NvPresent64, указанный в README аддона. Для неизвестного профиля LS продолжает обычный вывод без патчей драйвера.
Это готовый экспериментальный backend с проверками исполнения; совместимость с вашим конкретным NvPresent и RTX 3080 пока не установлена.

RTX HDR: отключите встроенный HDR LS, затем включите аддон и подтверждение в его меню. Четыре NVIDIA параметра соответствуют Magpie 0.6.9.
Auto использует HDR scRGB при включённом HDR Windows, иначе отображает HDR-результат через SDR tone map.
SDR display mode не включает аппаратный HDR монитора. Официальный TrueHDR runtime включён; ваши DLL DLSS FG для RTX 30 к нему не относятся.

Общий мост задаёт порядок: генератор -> RTX HDR для каждого кадра -> выбранный вывод. DLSS FG и Smooth Motion взаимно исключаются;
HDR может обрабатывать DLSS FG intermediates или передавать FP16 в Smooth Motion. Поддержка конкретных NVIDIA runtime combinations требует проверки на GPU.
Окна вывода HDR/SM являются отключёнными дочерними окнами LS; аддоны не перехватывают клавиатуру/мышь и не переключают foreground window.

VRR: лог 0.2.1 подтверждает active driver G-SYNC, но не измеряет частоту физического scanout.
Данная сборка использует законные tearing-флаги и проверяет GPU/вывод. Постоянные 144 Гц в OSD сами по себе не объясняют расхождение с индикатором NVIDIA.
Физическое VRR на вашей системе нельзя считать исправленным до проверки монитора; нет принудительного изменения стилей, фокуса, драйверных профилей или реестра.

Полные исходники трёх аддонов, общего моста, проверки и лицензии — в source. Runtime NVIDIA TrueHDR имеет отдельную лицензию SDK PDF.
CI включает x64 MSVC, WARP и тестовые провайдеры NVIDIA. Hardware DLSS/SM/TrueHDR и реальный G-SYNC в CI недоступны.
Проверяется также повторная установка: сохранность INI, вашего runtime для RTX 30, DLL менеджера и отдельные резервные копии заменённых файлов.
